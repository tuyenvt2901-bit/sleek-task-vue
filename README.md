# Zen Manager

VAI TRÒ: Bạn là kỹ sư sản phẩm cho các sản phẩm ứng dụng web tối thiểu khả thi (MVP). NHIỆM VỤ: Hãy tạo một phần mềm quản lý công nợ. Phần mềm phải có danh sách việc cần làm, cập nhật trạng thái như "Đang làm" và "Đã hoàn thành", bộ lọc trạng thái và trang báo cáo đơn giản. Tất cả các tính năng phải hoạt động cùng nhau với logic dễ hiểu. BỐI CẢNH: Thiết kế phải đẹp, tối giản và hoàn hảo cho điện thoại di động. Vui lòng cung cấp mã nguồn sẵn sàng chạy. Giao diện phải trông chuyên nghiệp, hiện đại và trẻ trung.
